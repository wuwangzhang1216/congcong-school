# v1.8.3：人教精通五上教材与语音

本版发布 [PR #63](https://github.com/wuwangzhang1216/congcong-school/pull/63)，对应 [issue #62](https://github.com/wuwangzhang1216/congcong-school/issues/62)。新增人教版（精通）五年级上册（2026秋版），与PEP并列，使用独立ID，保留原有教材及成绩。

包含6个单元、2节复习、96条词汇、32节小课、216道练习和36道挑战题。所需1,044条音频齐全，其中847条新增使用Edge TTS，197条复用既有音频；新增逐册AAC/M4A包。听读覆盖单元词汇，不包含整册课文、歌曲或原页点读。[来源与范围](../issue-62-jingtong-2026.md)。继承此前长数字输入、资源增量更新和续学计时修复。

## 安装或原目录升级

从 [v1.8.3 Release](https://github.com/wuwangzhang1216/congcong-school/releases/tag/v1.8.3) 下载新版 `install-release.py`：

```sh
python3 install-release.py --tag v1.8.3 --mode static --root /path/to/existing-site --dry-run
python3 install-release.py --tag v1.8.3 --mode static --root /path/to/existing-site
```

Windows将`python3`换成`py -3`。安装器自动复用一致的基础资源，仅下载新版页面、数据和所需音频增补包；无需先安装旧版本。源码部署使用`--with-source`更新匹配源码和转换缓存，然后`npm ci && npm run build`。请保留原协议、域名和端口，以保留浏览器学习记录。
